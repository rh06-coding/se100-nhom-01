## 1. Agent đã đề xuất gì?

Agent đã hỗ trợ khởi tạo cấu trúc thư mục repo chuẩn từ template môn học, thiết lập workflow CI GitHub Actions (`.github/workflows/kiem-moc.yml`), tạo trang tĩnh tối giản tại `src/index.html`, phân tích tài liệu đề tài `De_tai_Dat_cho_phong_tu_hoc.md` để mô hình hoá 5 lớp thực thể và 3 câu hỏi sâu cho khách hàng.

| Đề xuất | Ở đâu (tệp / sơ đồ) | Bản ghi hội thoại |
|---|---|---|
| Khởi tạo khung thư mục và workflow kiểm mốc | `scripts/kiem_moc.py`, `.github/workflows/` | `ai-log/M0-antigravity.md` |
| Sơ đồ lớp 5 lớp theo phân tích đề tài | `diagrams/class.mmd`, `diagrams/xem.md` | `ai-log/M0-antigravity.md` |
